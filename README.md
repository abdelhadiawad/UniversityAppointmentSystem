# University Appointment System

A full-stack web application for managing university appointment bookings between students and professors.

The system allows students to log in using their student number and national ID, automatically loads their faculty, department, academic level, and personal data from the database, then shows available appointments based on the student's department and academic level.

## Main Features

- Student login using student number and national ID
- Student profile page
- Department-based appointment filtering
- Course-based appointment booking
- Professor appointment slots
- Booking confirmation
- View student bookings
- Cancel bookings
- SQL Server database integration
- Node.js and Express backend
- HTML, CSS, and JavaScript frontend
